Before task 33 comparisons, verify fetched source/archive and binary hashes, licenses, compiler/options, native platform and required features; retain them in the case manifest. Native Windows iperf2 builds/runs with timer-handle pacing warnings; four Crusader scenarios run in isolated Linux WSL2. IRTT's supported 127.0.0.2 bind avoids its Windows MTU-sentinel buffer bug without a source patch: ten repaired-clock exploratory pairs retain 200 product/199 reference completions and one reference skip. Compatible baselines, independent boundary allowances and held-out bands remain pending. [Runtime evidence and limits](WORK_LOG.md#2026-10-13-reference-runtime-and-rendered-browser-progress). References remain external validation tools; changing a selected baseline requires an explicit new decision and fresh calibration.

Use the [existing acceptance matrix](DESIGN.md#reference-comparison-acceptance-matrix). Deterministic identities/counts/content have zero tolerance; timing retains documented timestamp quantization and observation boundaries. For each compatible tool/quantity/environment, collect **10 separate baseline pairs and 2 held-out pairs**, using explicitly matched workloads/windows and idle or named external load. Define an absolute engineering band from the largest baseline absolute delta plus independently documented boundary uncertainty, then freeze the manifest **before** held-out/target trials. A held-out failure invalidates that calibration case; do not widen a band to pass target trials. These counts/bands describe a reproducibility check, not statistical coverage or clock accuracy. Actual numerical bands require measurements and remain pending evidence. Unmatched quantities stay incompatible/inconclusive; do not pool quantiles or infer DNS/other-carrier support.
